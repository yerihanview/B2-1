## 품질 게이트
1. 구현 착수 전: 상세 명세와 예상 결과를 확정한다.
2. 자동 검수: 모든 필수 테스트 성공, 미검증 항목 명시.
3. 수동 검수: 핵심 기능과 재시작·오류를 실제 시연한다.
4. 승인: 공식 체크리스트를 항목별로 근거와 연결해 확인한다.

검수 대상과 근거를 분리하고, AI 생성 테스트 자체가 요구사항을 잘못 해석했을 가능성을 검토한다.
