# 자동 검수 실패 처리 정책 (v1.0)

> 범위: B2-1의 AI 구현 → 독립 검수 → 수정 → 재검수 → 인간 승인. 이 문서는 **운영 정책**이며 자동 복구 에이전트가 설치되었다는 뜻이 아니다.

## 역할
- AI 개발 에이전트: 기능 구현, 실패 로그 읽기, 원인 분석, 제한적 수정, 재검증, PR 업데이트.
- GitHub Actions: 지정된 테스트를 독립된 Runner에서 실행하고 결과·로그를 기록. **Actions 자체는 코드 수정하지 않음**.
- 사람: 명세와 코드의 충돌, 데이터 손실 위험, 반복 실패, 최종 병합 승인.
- `main`은 승인된 결과의 기준 브랜치. 기능 구현은 `feat/*` 또는 `fix/*` 작업 브랜치에서 PR로 제안한다.

## 상태 전이
```text
AI 작업 브랜치 → PR → CI 실행
                      ├─ PASS → 사람 최종 승인 → main 병합
                      └─ FAIL → 실패 분류 → AI 수정 → PR 업데이트 → CI 재검증
                                       ├─ 3회 이내 해결 → PASS 흐름
                                       └─ 3회 실패 / 위험 / 명세 충돌 → 사람에게 에스컬레이션
```
- 반복 한도 **동일 결함에 대한 자동 수정 시도 최대 3회**. 3회가 끝나면 반복 자동 수정 중단, 발견 원인·시도별 변경·잔여 실패를 보고.
- Runner/네트워크 등 일시 오류는 동일 SHA 재실행 1회 허용. 코드 결함의 수정 시도 횟수와 별도 기록.
- 수정 시 테스트의 기대값을 임의로 낮추거나 실패 테스트를 비활성화하지 않는다.
- 수정 후 해당 테스트뿐 아니라 전체 회귀 테스트 실행. 새 커밋 SHA의 CI 결과를 확인하며 이전 SHA의 성공은 재사용 불가.
- 데이터 손상·파일 교체/권한·동시성 안전성, 명세 자체의 변경이나 설계 경계 위반은 **자동 병합 금지** 및 사람 검토.
- **Branch protection/Ruleset과 필수 상태 검사가 실제 설정되어야** CI 실패 시 GitHub가 PR 병합을 막는다. 설정 전에는 '정책상 병합 금지'이며 기술적 강제는 아님.
- GitHub Actions의 실패 로그는 Actions에 보관한다. evidence TXT는 필요한 최종 결과만 생성하며 불필요한 커밋/스크린샷 수집을 하지 않는다.

## 오류 분류와 조치
| 유형 | 조치 | 인간 개입 |
|---|---|---|
| 일시적 Runner/환경 실패 | 동일 SHA 1회 재실행, 계속 실패 시 원인 보고 | 필요시 |
| 재현 가능한 코드 결함 | 실패 재현→수정→CI 재검증, 최대 3회 | 3회 실패 시 |
| 명세 모호성/상충 | 임의 추측 대신 spec/ADR 수정 제안 | 반드시 |
| 데이터 유실/보안·무결성 위험 | 수정 가능하나 최종 승인 전 반드시 설명·확인 | 반드시 |
| 정상 테스트 통과 | CI 성공 로그·잔여 위험 요약 | 병합 전 최종 승인 |

## 구현 단계
1. `.github/workflows/python-tests.yml`을 저장소에 추가: PR과 수동 실행에 Python 3.10+ `unittest` 실행.
2. 최소 실행 가능한 코드와 테스트를 추가한 뒤 CI의 실제 최초 결과 확인.
3. GitHub 저장소 Settings → Rules → Rulesets 또는 Branch protection에서 `main`에 대해 필수 상태 검사와 PR 병합 승인 규칙 설정.
4. AI 수정 루프는 개발 에이전트 연결 방식(클라우드 에이전트 또는 사람이 트리거하는 작업)에 따라 구현. **단순 CI YAML만으로 자동 수정까지 구현되는 것은 아니다.**
5. 자동화가 실제 동작하는지 의도적 테스트 실패→수정→재검증으로 확인한 뒤 결과를 README에 기록.

## 완료 조건
- PR CI 상태 검사 통과/실패 확인
- 실패 PR의 병합 방지 설정 확인
- AI 수정 시도 횟수 기록·상한 적용 확인
- 원인·로그·최종 수정 SHA·재검증 결과를 사람이 확인
