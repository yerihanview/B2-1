# 인수인계·설계 검토 기록

기준: GitHub main 8ccbc22ab03ec6531d3a4ffbac229f3df8ed7c19. 2026-11-02.
설계 검토와 검수 계획 검토를 별도 에이전트가 읽기 전용으로 수행했다.
프로그램과 tests/는 아직 없으며 기능 검수·CI 통과를 주장하지 않는다.

사용자가 발견 사항에 대한 권장 조치를 승인했다. 구현은 별도 착수 승인 전까지 하지 않는다.

## 반영한 결정

- 기존 CLI→Service→Repository와 표준 라이브러리, JSONL/CSV, 전건 롤백을 유지한다.
- export는 파일 순서다. 내부 파일·잠금 경로 및 별칭 덮어쓰기를 거부한다.
- 정확한 중복 ID 검출에 ID 집합 O(N)을 사용한다. 선택 힙만 O(K)이며 전체 명령 O(K)를 주장하지 않는다.
- 도움말/파싱 실패의 저장소 무접근, 전체 데이터 검증과 초기화 순서, 교체 전/후 실패를 구분한다.
- CSV/JSON/입력/반올림 경계와 추가 검수 T21~T27, P01, F11 점검을 명시한다.
- 독립 검증은 기대값 설계·테스트·결함 판정 책임, Actions는 실행기로 구분한다.
- PR·수동 Actions를 유지하고 0건/전체 스킵 성공을 차단한다. 보호 규칙 설정 여부와 실제 원격 CI 성공은 미확인이다.

## 남은 외부 대조와 한계

공식 미션 원문·평가표가 저장소에 없다. 옵션 표기, category/tag 문자 제한,
limit 상한, export 순서/기간 필수, 전체 메모리 요구는 원문 대조 전 미확인이다.
다중 파일 원자성, 강제 종료 자동 복구, 악의적 외부 경로 경합 방어는 제공하지 않는다.
미정의 동작이나 요구 충돌을 발견하면 구현 편의로 기대값을 정하지 않고 명세부터 보강한다.

## 다음 단계

문서·CI 변경 PR 검토 후 골격/모델/help, 저장소/잠금, 서비스, 조회/CSV,
통합 검수 순서로 진행한다. 독립 검증자는 명세 기반 기대값을 먼저 준비한다.
실제 실행 로그에는 대상 SHA·Python·명령·테스트 수·종료 코드를 기록한다.

## 계약·실행기 확인 결과

`git diff --check` 통과. Python 3.12.14에서 Actions의 실제 Python 본문을 추출해
임시 fixture로 정상(0), 0건(1), 실패(1), 오류(1), 전체 스킵(1)을 확인했다.
앱 테스트나 실제 원격 Actions 실행 결과가 아니다. 검증 담당이 수정 diff를 읽기 전용
재검토했으며 import 교체 전/후 실패 문구의 충돌을 추가로 수정했다.
