# B2-1 기능·데이터 상세 명세

> 상태: 작성 대기 · 아래는 명세 항목 목록이며 확정 동작이 아니다.

## 명령 계약
- 거래: add / list / search / summary / update / delete
- 카테고리: category add / list / remove
- 예산: budget set 및 summary 연계
- 데이터 교환: import / export
- 공통: 도움말, 잘못된 인수, 입력 검증, 메시지, 종료 코드

각 명령을 **입력·옵션·기본값 / 정상 출력 / 상태 변경 / 실패 사례 / 종료 코드 / 테스트 ID**로 구체화한다.

## 데이터 계약
- 거래 / 카테고리 / 예산의 저장 파일, UTF-8, 유효값, 고유 ID와 참조 제약
- CSV 헤더·컬럼 순서·타입·날짜 표현·중복 정책·잘못된 행 처리
- 파일 읽기·쓰기 중 실패와 프로그램 재시작 후 일관성
- 대용량 목록·검색의 스트리밍 및 정렬 계약

## 미해결
- `--` vs `-` 옵션 표기
- JSONL/CSV 기본 포맷
- 원자적 갱신과 rollback 범위
- 10만 건 성능 목표 및 측정 조건

**주의:** 구현은 미해결 항목의 해소 및 이 문서의 승인 이후에 시작한다.
